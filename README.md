# Cross the Wall

An agent-based model calibrated with the ELRI panel (2016–2023) on
intergroup attitudes in the Mapuche–State conflict. Mapuche and
non-Indigenous, four waves, an uprising in the middle, real territory.

The name has two readings on purpose. **Crossing the wall**: what
happens — or doesn't happen — between groups that share the same space
but not always the same world. The "Wall" in Wallmapu: the territory
where all this takes place isn't abstract. It's southern Chile. It's on
the map.

**Cross the Wall** doesn't predict individuals. It reproduces the
structural logic of ELRI's sampling design — real city blocks, empirical
ethnic composition, latent attitude trajectories calibrated against the
data — and projects what would have happened if the 2019 social uprising
had been more intense, milder, or had never occurred.
